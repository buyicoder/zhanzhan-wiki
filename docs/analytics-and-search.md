# Analytics and search foundation

## Design

The public Wiki remains static. A dedicated Umami 3.3.1/PostgreSQL service runs on the existing server, with its dashboard bound to loopback. Only the tracker script and collection endpoint are proxied publicly. No session replay or user identification is enabled.

The custom tracker runs only on wiki.zhanzhanai.com. It respects DNT/GPC and the browser-local opt-out. It sends one pageview per pathname navigation, reading-depth events for long articles, next-reading clicks and course entry clicks. Depth is a scroll proxy, not proof of comprehension. IP/device-based visitor counts are estimates, not exact people counts.

Only restricted utm_source, utm_medium and utm_campaign values are retained. Other query parameters, fragments and referrer paths are removed. Never put private information in campaign tags.

Example campaign link:

https://wiki.zhanzhanai.com/map/?utm_source=douyin&utm_medium=video&utm_campaign=wiki_intro

## Search

- Keep the sitemap and RSS generated by Quartz.
- Publish robots.txt with the sitemap URL.
- Prefer the official Wiki domain in canonical tags on both deployments.
- Structured data describes the existing author, website and page, without invented awards, ratings or publication dates.
- Canonical URLs are search hints, not SPA redirects. Only legacy meta-refresh pages trigger redirect resolution.

## Manual ownership steps

Search Console and Bing Webmaster Tools ownership verification remain pending. The owner must sign in and supply the appropriate verification token or authorize the DNS verification. A sitemap existing online is not proof of submission, indexing or AI citation.

After verification, submit https://wiki.zhanzhanai.com/sitemap.xml and inspect the homepage plus three representative article URLs. Record indexing results separately from visitor statistics.

## Content priorities

Start with three evidence-based articles: why filling all Base fields needs an execution manual; how to verify Agent completion; and lessons from generating voucher-and-attachment books. Use real examples, limitations and source references. No bulk AI-generated pages or guaranteed citation claims.

## Verification

Run `node scripts/test-wiki-analytics.mjs`, `npx tsx --test quartz/components/scripts/util.test.ts`, `npx tsc --noEmit`, and the self-host artifact verifier. Check the dashboard with a clearly identified test visit before excluding the owner's browser.
