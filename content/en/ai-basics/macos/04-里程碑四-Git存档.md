## What's the problem with this?

The faster Agent changes, the faster it gets out of control. Without a copy of the file, you can only pray that it doesn't get bad; there's Git, who dares to let it go wrong.

## What will you finish?

- Establishment of Git repository and first identifiable archive for exercise projects.
- Check differences before and after Agent changes, instead of listening to oral reports.
- One error was recovered and a quarantine experiment was performed in the branch.

## Criteria for success

You can confirm the status of the workspace prior to the change, modify it to understand the difference and create a clear submission; after the project has been deliberately altered, you can revert to the previous available status.

## Capacity migration

This set of actions can be moved to websites, documents, data scripts and any Agent projects. Git is not a programmer's identification, but a right to regret.
