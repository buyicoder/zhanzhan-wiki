## What's the problem with this?

Projects that exist on their own computers are difficult to collaborate and cannot prove the process. GitHub's value is not just a “cloud disk”, but rather a tracking link that places needs, modifications, reviews and versions in the same way.

## What will you finish?

- Save one local project to GitHub and retake it elsewhere.
- Writes a requirement with Issue and finishes the change in a separate branch.
- Launch Pull Request to check differences and consolidate them, leaving a complete record of collaboration.

## Criteria for success

The repository can be retrieved and run from empty folders; another can only look at Issue, submit and PR, and know what needs are, what changes are made and how to accept and accept.

## Capacity migration

You start using items as digital assets, not as temporary outputs in chat windows. Later, in collaboration with humans or Agent, it is possible to talk about the product of the walk, not over and over again.
