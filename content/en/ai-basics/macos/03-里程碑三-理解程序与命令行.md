## What's the problem with this?

Agent will knock on the order for you, but if you have no idea what the program, parameters, documentation and side effects are, you can't judge if it's doing the right thing. This does not train White as a programmer, but rather adds a minimum computer intuition.

## What will you finish?

- The commons and differences between LLM and normal programs are understood with the "Input box box output".
- Runs a calculation-only application and observes a program that creates files.
- Use the terminal to complete basic actions such as moving directories, viewing files and running scripts.

## Criteria for success

You can explain in your own words why the program has changed the computer state, you can see where the order Agent is prepared to execute roughly, and you can run a simple Python program and a batch script independently.

## Capacity migration

In the future, when Agent makes a mistake, you distinguish between commands, paths, privileges and procedural logic; in the face of unknown tools, you can judge risk from input, output and side effects.
