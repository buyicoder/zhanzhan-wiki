## What's the problem with this?

Tools will be installed, commands will be knocked on, not the same as complete projects. The graduation test is whether you can define the results, dismantle the stages, get Agent to work, check and accept yourself, and return to the safe filing point if you fail.

## What will you finish?

- Create a browser version of the snake-eating project from an empty directory.
- Interfacing, movement, control, food scoring, failure rules, reopening and gradual document delivery.
- Saves each available stage with Git and places the whole process in GitHub.

## Criteria for success

The game can start, move, turn, eat, change, score, fail and restart; a new folder can still run after retake.

## Capacity migration

What is really transferable is not the snake code, but the command method of “target-phase-success criteria-check-archiving”. It can be used for websites, office automation, data tools and more sophisticated software.
